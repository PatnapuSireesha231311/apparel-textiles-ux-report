# Thread & Loom — Apparel and Textiles Storefront

A responsive front-end demo for an apparel and textiles e-commerce website. Built with HTML, CSS, and vanilla JavaScript; no build tools or external libraries are required.

## Features
- Responsive mobile, tablet, and desktop layout
- Mobile navigation menu
- Product cards with category filtering, search, and sorting
- Add-to-bag interaction, quantity controls, remove item, and subtotal
- Save/favourite product button
- Newsletter form feedback (demo only)
- Keyboard focus styles and reduced-motion support
- Editorial, textile-inspired colour palette

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

Optional: use the VS Code Live Server extension for local preview.

## Publish with GitHub Pages
1. Push these files to the `main` branch of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the Pages screen will show the URL.

## Important demo notes
This is a front-end prototype. The products, prices, saved items, and shopping bag are demo data and are not stored on a server. Checkout does not process payments, and the newsletter form does not send emails. A production store needs a backend, inventory management, secure payment integration, privacy policy, and real product photography.

## Project files
- `index.html` — page structure
- `style.css` — design system and responsive styles
- `script.js` — search, filter, sorting, saved products, and shopping bag interactions
